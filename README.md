# 🧩 Project Management App (Jira-like) — Work in Progress

> A lightweight, customizable issue and project tracking system inspired by Jira.
> ⚠️ This project is currently under active development.

---

## 🚧 Status

This application is a **work in progress**. Features are actively being developed, improved, and refactored. Expect incomplete modules and breaking changes.

---

## ✨ Features (Planned & In Progress)

* 📋 Project and workspace management
* 🐞 Issue / ticket creation and tracking
* 🏷️ priorities and statuses
* 👥 User roles and access control
* 📊 Dashboard with analytics
* 📝 Comments and activity tracking
* 🔔 Notification system (planned)
* 🔍 Search and filtering

---

## 🛠️ Tech Stack

* **Backend:** Spring Boot (Java)
* **Frontend:** Thymeleaf (Server-side rendering)
* **Database:** MySQL
* **ORM:** Hibernate / JPA
* **Build Tool:** Maven
* **Authentication:** Spring Security

---

## 📦 Installation

### Prerequisites

* Java 17+
* Maven
* MySQL Server
